STEP 1 사전 확인 완료됨
출금 가능 달러(결제 완료분) 확인
미국 주식 매도 대금은 결제일이 지나야 출금·환전 가능 금액으로 잡힙니다. 화면의 '출금 가능' 금액이 기준입니다.
카카오페이 앱 이동 경로
카카오페이 앱 → 증권 (증권홈) → 내 계좌 → 출금 → 달러
확인 완료
화면에 표시된 총 달러 잔고와 환전(출금) 가능 달러 금액이 일치하는지 확인 완료했습니다.
STEP 2 현재 진행할 순서
우대 시간에 달러 → 원화 환전
환전은 24시간 가능하지만 95% 환율 우대는 영업일 09:00 ~ 16:00에만 적용됩니다. 그 밖의 시간·주말·공휴일에는 기본 스프레드 1%가 그대로 붙습니다.
카카오페이 앱 이동 경로
증권홈 → 내 계좌 → 환전 → 달러(USD) → 원화(KRW)
순서 1
카카오페이 증권 [내 계좌] → [환전] 메뉴를 터치합니다.
순서 2
상단 환전 방향이 [달러 USD] → [원화 KRW]로 되어 있는지 확인합니다. (반대라면 가운데 화살표 아이콘 터치)
순서 3 · 핵심 팁
금액을 직접 치기보다 [전액] 버튼이나 '환전 가능 금액' 표시를 눌러 입력하세요. 센트 단위 자투리까지 빠짐없이 들어갑니다. 입력된 금액이 1단계에서 본 출금 가능 달러와 같은지 확인합니다.
순서 4
적용 환율에 우대가 표시되는지, 예상 원화 금액이 맞는지 확인한 뒤 하단 [환전하기] 버튼을 눌러 완료합니다.
참고용: 환전 예상 수령액 계산기 (기준 환율 = 매매기준율)
우대 시간(09:00~16:00) 환전 0 원
우대 없는 시간 환전 0 원
우대 시간에 하면 더 받는 금액 0 원
STEP 3 원화 정산 점검
원화 예수금 입금 및 정산 상태 확인
환전된 원화가 내 카카오페이증권 계좌에 정상적으로 입금되었는지 확인합니다.
확인 경로
카카오톡 알림톡 확인 또는 증권 내 계좌 홈 → 원화 잔고 확인
확인 1
카카오톡 알림 또는 계좌 홈에서 원화 잔고(출금 가능 원화)에 환전 금액이 들어왔는지 확인합니다.
⚠️ 주의: 밤·주말·공휴일에 환전하셨나요?
시간외 환전은 스프레드를 먼저 적용해 입금한 뒤 다음 영업일 오전 09:30경 실시간 환율로 재정산해 차액을 돌려주거나 추가로 가져갑니다. 원화를 전액 빼려면 재정산이 끝난 뒤 이체해야 추가 징수분 때문에 잔고가 모자라지 않습니다.
STEP 4 최종 이체 단계
토스 계좌로 원화 송금(이체) 실행
확정 입금된 원화를 수수료 없이 토스뱅크(또는 토스증권) 계좌로 옮깁니다.
카카오페이 앱 이동 경로
내 계좌 → 송금 (또는 출금) → 토스뱅크 / 토스증권 선택 → 보내기 완료
순서 1
카카오페이 증권 [내 계좌] → [송금] (또는 출금) 버튼을 터치합니다.
순서 2
받는 은행을 토스뱅크(또는 토스증권 연계 계좌)로 선택하고 본인 계좌번호를 입력합니다.
순서 3
환전된 원화 전액을 입력하고 [보내기]를 눌러 인증을 마치면 토스 계좌로 즉시 입금됩니다.
💡 메뉴가 안 보이면:
앱 버전에 따라 [송금] 대신 [출금]·[이체]로 표시될 수 있습니다. 받는 계좌가 목록에 없으면 먼저 본인 명의 토스뱅크 계좌를 출금 계좌로 등록하세요. 토스 앱의 [채우기]로 카카오페이증권 계좌를 불러올 수 있는지는 앱에서 직접 확인이 필요합니다.
